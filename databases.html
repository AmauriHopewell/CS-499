What changed

create, read, update, and delete go through one module. animal_id has a unique index. Lookups go through an allow-list, and an operator key such as $where is rejected. Staff and admin share one Mongo login from the environment. The dashboard role decides who can write. An empty lookup on delete returns 0. The original delete used many=True.

python -m pytest tests -q is 12 tests on mongomock. If MONGO_USER and MONGO_PASS are empty, python dashboard.py opens that same in-memory data with seven sample dogs. No cluster is required for that path. When credentials are set, live Mongo defaults to localhost port 27017.

Still open, and called out in the self-assessment: the unique index can fail on a dirty AAC dump, aggregation groups outcome_type, the dashboard is a table and a pie chart, and the insert payload is not allow-listed. The original constructor on main still has its course defaults. The enhanced module does not copy them.

How to run

From the enhanced folder on cs499-milestone-four:

python -m pip install -r requirements.txt

python -m pytest tests -q

python dashboard.py

Then open http://127.0.0.1:8050.
