What changed

ContactService still owns the CS-320 field rules. The id is final. Names are at most 10 characters. The address is at most 30. The phone is ten digits. A repository sits under that service. Tests use an in-memory HashMap. The running service uses SQLite. ContactApi is a JDK HttpServer, one class, not Spring.

AuthService has staff and admin. Passwords come from CONTACT_STAFF_PASSWORD and CONTACT_ADMIN_PASSWORD. The process exits if those are missing. A missing token is 401 with {}. A staff token on a write is 403 with {}. AuditLog records actor, action, id, and status. It does not take a phone number. mvn test is 37 tests.

How to run

From the enhanced folder on cs499-milestone-two, with JDK 17 and Maven:

mvn test

The original Eclipse tree (packages Contact, com, and Src) stays on main. The enhanced tree uses edu.snhu.contact.
