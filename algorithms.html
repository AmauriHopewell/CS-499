What changed

The original program kept courses in a vector. The enhancement times that vector against a BST and a hash map on the 129-course file. A sorted insert into a BST becomes a chain, so the tree is filled from the median of the sorted ids. Menu 6 prints a topological schedule from the prerequisite list.

Compare mode only means something if the binary is built with /O2. The enhanced README has that command.

How to run

From the enhanced folder on cs499-milestone-three, after the Visual C++ environment is loaded (the README has the vcvars64 line):

cl /EHsc /std:c++17 /O2 Proj2.cpp /Fe:Proj2.exe

Then run Proj2.exe and use the compare option and menu 6. The original Proj2.cpp stays on main.
